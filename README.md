## 🐛 Report a Bug

Found something that doesn't work as expected?

Please [**open a new issue**](https://github.com/ToHubLab/bug-report-for-TimeTracker-Pro/issues/new/choose) and provide as much detail as possible.

A helpful bug report includes:

- **Description:** What went wrong?
- **Steps to reproduce:** How can the issue be reproduced?
- **Expected behavior:** What should have happened?
- **Actual behavior:** What happened instead?
- **Environment:** Your browser version and operating system.
- **Screenshots:** Images or error messages, if available.

## 💡 Suggest a Feature

Have an idea that could make TimeTracker-Pro better?

We welcome suggestions for new features, improvements, and usability enhancements.

Please [**create an issue**](https://github.com/ToHubLab/bug-report-for-TimeTracker-Pro/issues/new/choose) and describe your idea and how it would help users.

## 💬 Community Guidelines

To help keep this repository useful for everyone:

- Search existing issues before creating a new one.
- Be respectful and constructive.
- Provide clear and relevant information.
- Do not post passwords, access tokens, or personal information.
- Never share sensitive security vulnerabilities publicly.

## 🔒 Privacy & Security

This is a public repository. Issues, comments, and uploaded attachments may be visible to everyone.

Please do not share confidential information or private data.

For security vulnerabilities, contact **ToHubLab** privately rather than reporting them publicly.

## 📌 Important Information

- This repository is for feedback, bug reports, and feature requests.
- The project source code is maintained privately.
- Creating an issue does not grant access to the source code.
- Feature suggestions are welcome, but implementation is not guaranteed.
